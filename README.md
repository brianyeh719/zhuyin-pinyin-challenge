# 注音拼音挑戰（Three.js 2.5D 夜市雙拼 × 九份淘金互動學習遊戲）

基於 **Three.js + Vite** 打造的 2.5D 互動學習遊戲，結合 **角色移動探索**、**獨立攤位 Idle／Action 動畫**、**學習區與練習區雙地圖** 以及 **遊戲式注音雙拼挑戰 UI**。

## 兩大區域地圖
1. **📖 學習區（九份淘金與注音學堂）**
   - **注音對照大黑板**：收錄完整 21 聲母 ＋ 16 韻母（含介母 ㄧㄨㄩ 及 `ㄝ / ê` 隱藏教學提示），點擊即可發音。
   - **九份溪邊淘金台**：注音 ⇄ 拼音 雙向識別測驗，蒐集 37 枚金砂圖鑑。
   - **雙拼積木實驗桌**：自由組合聲母、韻母、聲調，即時對照拼音並關聯夜市實戰食物。
2. **🏮 練習區（台灣夜市 17 攤雙拼街）**
   - 收錄全部 17 個獨立攤位／遊樂設施物件（珍珠奶茶、雞排、大腸、滷味、排骨酥、臭豆腐、肉圓、魚蛋、糖葫蘆、芭樂、烤玉米、炸魷魚、鴨頭、撈魚、打彈珠、娃娃機、烤麻糬）。
   - 每個攤位具備專屬 **Idle**（搖曳燈籠、店員呼吸、金魚游動、娃娃機天車巡航、炭火微光、熱氣飄散）與 **Action**（手搖飲晃動、油鍋酥炸噴花、炭火翻烤、天車下爪夾小熊、紙網撈魚水花、彈珠閃燈跳躍）動畫。
   - 所有題目均標註 **（國語讀音）**，支援 `zh-TW` 語音朗讀、聲母＋韻母積木雙拼、考察點解析與全詞讀音卡。

## 啟動方式
```bash
npm install
npm run dev
```
或直接雙擊執行 `start.bat`。

## 操作說明
- **角色移動**：`WASD` / 方向鍵、點擊地面移動、或使用右下角虛擬方向鍵
- **開啟攤位／切換地圖**：靠近攤位或牌樓按 `E` / `Space`、點擊畫面互動鈕、或直接點擊 3D 攤位
- **視角縮放**：滑鼠滾輪
